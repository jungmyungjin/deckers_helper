# UI 초안 (Mockup v2 — Gold × SMC 모델)

모바일 PWA 기준. 화면 6종. 완주 기준을 **Gold 미션 × SMC = 84칸**으로 확정한 버전.

## 정보구조 (하단 탭 5개)

```
🏆 보드   🎲 챌린지   ➕ 기록   📜 히스토리   👤 프로필
```
- 목표 카드 뷰어(뒤집기)는 독립 탭이 아니라 챌린지/기록 흐름 안에 넣는 방향 검토(Q1/Q3).

## 화면별 구성

### 1. 도장깨기 보드 (홈)
- **Gold 12(열) × SMC 7(행) = 84칸** 매트릭스, 가로 스크롤.
- 셀 상태: 빈칸(미도전) / ✓(승리) / 🥇(대성공 판 있음).
- 상단: 도장 n/84, 플레이 수, 대성공 수 + 진행 바.
- Gold 코드: BLK Blackout · DDF Distributed Defense · DNI DNI Web · FLD Flash Flood · HAK HackMan · INS Insert Misinfo · MSG Message Queue · MIR Mirror Map · NEU Neutrino · ROM Roman Road · SIM SimSmudge · WTR Waterfall.
- 셀 탭 → 화면 2.

### 2. 셀 클릭 → Gold 미션 도전 히스토리 ★핵심
- 헤더: "HackMan × Sentinel", 상태 배지.
- 요약: 도전 n · 승리 n · 대성공 n · 실패 n.
- 도전 리스트(최신순): 각 판마다
  - 결과 배지(🥇/✓/✕)
  - **조합 3장**: Copper + Silver + Gold (칩)
  - 덱커·플레이어(색 점 + 이름)
  - 날짜·시간.
- 실패한 판도 여기 남음.

### 3. 새 기록 입력
- 보스 선택 → 덱커별 조종자 지정 → 사이클별 성공/실패 토글.
- 최종 Gold 성공 여부가 그 Gold×보스 셀 도장을 결정.
- 결과(실패/성공/대성공) 자동 계산 미리보기.

### 4. 셔플 / 랜덤 챌린지
- 아직 못 깬 Gold×보스 우선 제안 + Copper/Silver 자동 셔플 → 완전한 조합 한 세트 생성.
- "이 셋업으로 기록 시작"으로 화면 3 연결.

### 5. 목표 카드 뷰어 (뒤집기)
- 현재 목표 카드 크게 표시 → 탭하면 SUCCESS/FAIL 뒷면으로 3D 플립.
- 플레이 중 뒤집기를 곧 사이클 기록으로 쓰는 통합안 검토(Q3).
- 카드 내용은 실물 입력 전까지 이름/보안레벨만.

### 6. 프로필 · 업적 · 로그인
- 게스트(로컬) 사용 + Google 로그인 동기화.
- 완주 게이지(84) + 승률 + 업적 그리드(잠금/해제).
- 조합/덱커 다양성은 "조합 수집가" 같은 업적으로 보상.

## 비주얼 방향

- 사이버펑크 터미널: 딥 바이올렛 잉크 배경 + 보안레벨 메탈 컬러(Copper/Silver/Gold) 액센트 + 시안 인터랙션.
- 폰트: Chakra Petch(디스플레이) / IBM Plex Sans KR(본문) / IBM Plex Mono(라벨·코드).
- 서버 색: red/green/yellow/blue/purple 점으로 덱커 구분.

## 셀 클리어/상태 규칙(제안)

- 셀 클리어: 그 (SMC, 최종 Gold) 조합으로 **outcome ≠ fail** 인 런이 1개 이상.
- 🥇 대성공 승격: 그 셀에서 outcome = perfect 런이 1개 이상.
- 진행 게이지: 클리어된 셀 수 / 84.
